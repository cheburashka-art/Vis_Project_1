# Pulse — дашборд вовлечённости в онлайн-тренировках

Интерактивная визуализация для домашнего задания по визуализации данных, вариант 2.

Ключевой вопрос проекта:

> Как меняется вовлечённость пользователей на протяжении программы и какие тренировки на неё повлияли?

## Файлы проекта

- `index.html` — полностью готовый автономный дашборд;
- `README.md` — инструкция по публикации;
- `Онлайн-тренировки, 10 недель.xlsx` — исходный Excel-файл.

Данные из Excel агрегированы и встроены непосредственно в `index.html` в виде JSON. Поэтому при публикации не требуется загружать Excel-файл, подключать внешний JSON или настраивать CORS.

## Возможности дашборда

- тёмная тема включена по умолчанию;
- переключение между тёмной и светлой темой;
- выбор периода анализа «От — До» по неделям;
- KPI за выбранный период:
  - общее количество просмотров;
  - количество пользователей;
  - средняя глубина просмотра;
  - неделя с максимальным количеством просмотров;
- атомарный график «Вовлечённость каждой тренировки»:
  - один визуальный блок равен одному просмотру;
  - ось Y показывает отношение просмотров тренировки к активным пользователям недели;
  - ось X содержит даты, разбитые на недельные интервалы;
  - цвет каждого просмотра меняется от красного к зелёному в зависимости от вовлечённости тренировки;
  - цветная и серая части блока показывают просмотренную и непросмотренную доли записи;
  - при наведении на отдельный блок отображаются ID просмотра и пользователя, глубина, длительность и оценка;
  - при наведении на точку линии отображаются агрегированные показатели всей тренировки;
  - под осью последовательно показаны строки «Тип», «Тренер», «День», «Дата»;
  - цветные метки показывают тип тренировки;
  - красной рамкой отмечаются кандидаты на перезапись;
  - фильтр сегментов показывает предпочтения пользователей с минимальной, средней и высокой вовлечённостью;
    - минимальная вовлечённость — до 19 просмотров за всю программу;
    - средняя вовлечённость — от 20 до 51 просмотра;
    - высокая вовлечённость — от 52 просмотров;
  - отдельные фильтры позволяют выбрать тренера и тип тренировки;
- атомарный график «Тренеры и их сильные типы тренировок»:
  - тренеры расположены по возрастанию средней оценки;
  - типы внутри каждого тренера расположены по убыванию средней оценки;
  - под каждым столбцом указана средняя оценка соответствующего типа;
  - каждый столбец соответствует типу тренировки;
  - высота столбца показывает агрегированную глубину просмотра;
  - каждый атом внутри столбца соответствует коду конкретной тренировки;
  - tooltip показывает код, неделю, тип, тренера, просмотры, глубину и оценку;
  - автоматически определяется лучший тип каждого тренера по глубине;
  - показатели пересчитываются при изменении периода;
- график «Что формирует объём просмотров?»:
  - составные вертикальные столбцы по неделям;
  - отдельный цвет для каждого типа тренировки;
  - tooltip с количеством просмотров и долей типа;
- график «Типы тренировок» со сравнением средней глубины просмотра;
- более 50 интерактивных точек/сегментов данных.

## Локальный просмотр

1. Скачайте или скопируйте проект на компьютер.
2. Откройте файл `index.html` в браузере.
3. Для работы графиков требуется подключение к интернету, так как Tailwind CSS и Chart.js загружаются через CDN.

## Публикация на GitHub Pages

### 1. Создайте репозиторий

1. Войдите в аккаунт GitHub.
2. Откройте страницу [https://github.com/new](https://github.com/new).
3. Введите имя репозитория, например:

   ```text
   online-workouts-dashboard
   ```

4. Выберите `Public`.
5. Нажмите **Create repository**.

### 2. Загрузите файлы

1. В открывшемся репозитории нажмите **Add file → Upload files**.
2. Загрузите минимум два файла:

   ```text
   index.html
   README.md
   ```

3. Исходный Excel-файл можно также загрузить для подтверждения источника данных, но для работы сайта он не нужен.
4. Внизу страницы нажмите **Commit changes**.

Важно: файл должен называться именно `index.html` и находиться в корне репозитория.

### 3. Включите GitHub Pages

1. Откройте вкладку **Settings** репозитория.
2. В левом меню выберите **Pages**.
3. В разделе **Build and deployment** выберите:

   - **Source:** `Deploy from a branch`;
   - **Branch:** `main`;
   - **Folder:** `/ (root)`.

4. Нажмите **Save**.

Через некоторое время GitHub покажет публичный адрес сайта, обычно в формате:

```text
https://ВАШ-ЛОГИН.github.io/online-workouts-dashboard/
```

### 4. Проверьте публикацию

Откройте опубликованный адрес и проверьте:

- отображается ли тёмная тема;
- переключается ли светлая тема;
- меняются ли KPI при выборе периода;
- реагируют ли графики на выбор тренера и типов тренировок;
- появляются ли tooltip-подсказки при наведении на графики.

Если открывается старая версия страницы, обновите страницу с очисткой кеша: `Ctrl + F5`.

## Публикация через Git командную строку

Если Git уже установлен, команды будут такими:

```bash
git init
git add index.html README.md
git commit -m "Add workout engagement dashboard"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/online-workouts-dashboard.git
git push -u origin main
```

После загрузки включите GitHub Pages через **Settings → Pages**, как описано выше.
